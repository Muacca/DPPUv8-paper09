# Fermions at spherical throats of fixed-charge Nieh–Yan semi-wormholes

Muacca · DPPUv8 Paper 09 · **Version 1** · First release 2026-11-22

On a finite Euclidean axion collar with a spherical space-form throat, two vacuum preparations differ by a finite-rank projector onto a single spinor shell. Its positive Weyl number is $`s m_s`$ ; the vector number of a Dirac field cancels. With continuous mixed APS domains the relative four-component log modulus is $`-2J\eta_0`$ for fifteen spin lifts. A real Holst coupling moves the lowest Lorentzian crossing away from the throat. The real three-form stability calculation distinguishes fixed flux, continuous flux integrated at fixed outer field, and finite versus infinite outer radius.

Paper 08 supplies oriented spinor conventions. The manuscript specifies the angular data and domains again so that the comparisons can be reproduced from this repository alone. Relative numbers refer to the two prepared vacua on the same geometry. The shell-first Jost prescription at infinity and the compact relative determinant have separate definitions. Neither an individual noncompact absolute determinant nor a gravitational transition probability is supplied.
